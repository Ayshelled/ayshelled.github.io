# webtech-lab-01
Second Lab Homework : https://ayshelled.github.io/webtech-lab-01/

The new interactive features are the following:
- TV Show Section: This section, located by clicking "Shows" on the links in the top of the web page, displays a table of TV shows. The user can add a new show in the section "Add New Show" or filter them by utilizing the "Filter Shows" section.
- Contact Form: The contact form now displays an error when fields are missing, thus not letting the user send a message until they are filled.
- Toggle Theme Section: On the bottom of the website, or by clicking the "Theme" link, the user can change between light and dark themes.
